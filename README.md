Minimal React Todo App

Quick start:
1. Create a new Create React App project if you don't have one:
   npx create-react-app todo-app
   cd todo-app

2. Replace the files in src/ with the provided src/App.js, src/index.js, src/index.css.
   Replace public/index.html with the provided file.

3. Install (if needed) and start:
   npm install
   npm start

The app provides:
- an input and "Add" button to add tasks (Enter also adds)
- a simple list of tasks
- a "Delete" button on each task to remove it

That's it — a minimal todo app with only add and delete functionality.
